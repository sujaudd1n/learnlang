# Practice

You have done the basics like conditionals (if-else), iterations (loops), user input, is assumed.

Examples are shown in python but applicable to all languages.

## 1. Budget for food

Assume you are a college student and have limited money to spend on food. Write a
program that takes a command line argument montly budget and calculates amount of
money you can spend for that month for food and how much per-day you can spend
for food.

Example:

Amount is in rupees.

```bash
$ python food.py 10000
Total -> 4000
Per-day -> 133
```

## 2. Wakeup

We all have goals. To remind yourself your goals and time is constantly moving forward
write a program that shows

- your age in year, month, day format.
- how much the current year is left and completion percentage
- a list of your goal that is read from a file.

Make sure that you read the goals from a file, not hard coded `print` statement.

Example:

```bash
$ python wakeup.py
Age: 23 years, 7 months, 16 days
Year left: 0 years, 1 months, 29 days. 83.562% complete

## Goals

- your big dreams
- and more
```
